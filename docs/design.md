# 寝ずの番 | The Wake — ゲームデザイン v0.2

一人称・3D・ジャパニーズホラー。チラズアート型（狭い日常の場所 × 仕事ループ × 徐々に異変 × 伝承 × VHS）。
プレイ時間 20〜30 分、**一夜構成**(v0.2 で三夜から圧縮)、エンディング4種。周回前提。

## 1. コンセプト

- プレイヤー: 田舎の家族葬ホール「やすらぎ会館」の新人アルバイト。初めての宿直（寝ずの番）。
- 故人: 春日キヨ（88）。自宅で死亡。火葬場が友引と予約で埋まり、出棺まで三晩安置される。
- 一言: **線香を絶やすな。猫を入れるな。眠るな。**
- 怖さの源は「仕事ループそのもの」。線香のタイマーが、プレイヤーを一番怖い部屋（棺のある式場）へ何度も引き戻す。
- 伝承の裏付け: 寝ずの番は本来「火を絶やさず魔を寄せ付けない」ための風習。火車（かしゃ）は罪ある者の亡骸を奪う猫の妖怪。「猫が遺体をまたぐと起き上がる」。**メカニクス＝伝承**になっている。

## 2. 五つの掟（ゲーム内クリップボード）

1. 線香を絶やさぬこと
2. 灯明（ロウソク）を絶やさぬこと
3. 猫を建物に入れぬこと
4. 棺の小窓を開けぬこと
5. 眠らぬこと

掟を破る → 隠しパラメータ「異変度」が上がる。異変度で怪異の強さとエンディングが決まる。

## 3. コアループ

### 時間
- 一夜 = 21:00 → 05:00（ゲーム内8h）。1ゲーム時間 = 実時間3分 → 一夜 約24分。
- 時刻はVHSのタイムスタンプとして常時HUD表示（カムコーダー風 `PM 11:32`）。クロックとフィルタを兼ねる。

### 線香（主ループ）
- 1本 = 1ゲーム時間（実3分）。燃え尽きる前に式場に戻って次を立てる。
- 燃えている途中でも次を立てられる（タイマー上書き）。長い用事の前に「立て直してから行く」判断が生まれる。
- 在庫: 祭壇の引き出しに1箱（10本）。切れたらバックヤードの在庫棚へ取りに行く（用事を生む）。
- 絶えた瞬間: 異変度 +1、棺の中から「コン」と一度音がする。

### ロウソク（光）
- 1本 = 4ゲーム時間（実12分）。一夜に2回交換（1:00頃・5:00頃）。
- 消えると式場が暗くなる（線香の火だけ）。怪異が強まり、猫が寄りやすくなる。線香＝結界、ロウソク＝光、で役割を分ける。

### 用事（プレイヤーを式場から引き剥がす）
- 供花の水替え（バックヤードの水道 ↔ 式場）
- ドライアイス交換（バックヤードの冷凍庫 → 棺）。運搬中は両手が塞がり他の操作不可。棺の小窓越しに顔を見る唯一の機会。
- 電話対応（事務所）。30秒以内に取らないと異変度 +1（二夜目以降）。
- 施錠巡回（勝手口・窓）。開いていると猫の侵入口になる。
- ブレーカー復旧（バックヤード）。

### 猫
- 二夜目から建物の外周に出現。開いた勝手口・窓から侵入。侵入後は徘徊 → 式場 → 棺へ向かう。
- 見つけたらインタラクトで追い出せる。
- **猫が棺をまたぐ**: 異変度 +3、確定イベント（棺が軋む。以降、小窓の顔の向きが変わる）。

### 異変度（隠し）
- 0〜2: 静か。3〜5: 環境系の怪異が増える。6以上: 三夜目の終盤で「火車」エンド確定。
- 加算のみ。減らない。

## 4. マップ（平屋・L字・屋内7室＋外周）

```
[駐車場・外周・自販機]──勝手口──[バックヤード: 冷凍庫/在庫棚/分電盤/水道]
                                        │
[玄関]──[受付ホール]──────[廊下]──────[式場: 棺・祭壇・遺影・供花]
            │               │  │
        [事務所]        [控室(和室)] [トイレ]   [湯灌室(施錠、三夜目に開く)]
      電話/モニター/金庫    布団/TV/茶
```

- 式場 ↔ 事務所 は徒歩約10秒。式場 ↔ バックヤード 約8秒。距離＝緊張。
- 走れない（歩行 2.5 m/s のみ）。懐中電灯なし。館内の照明だけ。
- 事務所のモニターは2ch（式場・玄関）。ノイズ混じり。脅かしに使う。

## 7. エンディング

| 名 | 条件 | 内容 |
|---|---|---|
| 朝（ノーマル） | 終盤を生き延びる。異変度 < 6 | 出棺。霊柩車の屋根に猫が一匹座っている |
| 火車（バッド） | 異変度 ≥ 6、または猫が棺をまたいだ | 灯し直しが失敗する。朝、棺が空。社長が揉み消す。火葬場で息子が空の棺の前に立つ |
| 代わり（真） | 息子を断り、終盤に控室の戸を開ける | 火車は息子を連れて行く。翌朝、警察。孫娘が猫を一匹連れて帰る |
| 遺影（バッド） | 三夜目に布団で「休む」を選ぶ | 目覚めると朝。線香は絶え、棺は開き、祭壇の遺影が自分の顔になっている |

真エンドは「掟を破る（戸を開けて猫＝火車を通す）」で到達する。チラズアート式。

## 8. 演出方針

- 一夜目は本当に何も起こさない。「三周目まで溜める」。
- 脅かしは音優先: 冷蔵庫の唸り、時計、遠くの国道、線香の燃える微音、畳の足音、電話のベル、猫の声、棺の内側の引っ掻き。
- 季節は晩秋。寒いから猫が暖を求めて入ってくる（侵入の理由づけ）。ドライアイスと火の意味も通る。
- 追いかけっこは終盤の1回だけ。速度は遅め、廊下の角で見失うくらい。
- VHS: 640×360 で描画して拡大、ノイズ・色にじみ・走査線・ビネット・微ジッター・タイムスタンプ。

# v0.2 変更: 一夜構成(20〜30分)への圧縮

三夜(72分)は長すぎるので、**一夜 21:00→05:00 = 実時間24分**に圧縮する。三夜の要素は一夜の中で段階的に起こす。
