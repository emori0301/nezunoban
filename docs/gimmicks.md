1. 真相が収集物4枚の中だけにあり、読まなくても進む。読んでも要約されない。

3. 「かえして」が何を返せなのか示していない。
4. エンディング文が短く、真相の答え合わせが無い。

## D. 追加案

### D-1 謎解き(答えが館内にある)
1. **金庫はダイヤル式に**: 社長の机の鍵ではなく4桁。手掛かりは遺影の裏の命日/芳名帳の記帳日/花輪の札。
2. **分電盤のブレーカー3本**: 掲示の配線図どおりの順で上げないと、上げた瞬間に別の部屋が落ちる。
3. **芳名帳と花輪の照合**: 花輪の贈り主のうち1人が芳名帳に無い→その名は前任の宿直(日誌の筆者)。
4. **湯灌室の鍵は猫の首輪の中**: 追い出した猫が落とす/自販機の前の猫が咥えている。
5. **電話を自分からかける**: 貼り紙の社長の番号→出ない。孫娘の番号→「父が…」。キヨの家の番号→猫の声。
6. **遺影の裏の隠し引き出し**: 日記の最後のページ(猫を頼む/誠を許すな)。
