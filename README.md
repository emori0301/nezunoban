# 寝ずの番 | The Wake

チラズアート型の一人称 3D ジャパニーズホラー。田舎の家族葬ホールで、出棺までの一夜(実時間 約24分)を宿直として過ごす。

## 遊び方

```bash
./play.sh            # 起動(タイトル画面から)
./play.sh -- --skip-title --time=01:00   # デバッグ: 途中の時刻から
```

| 操作 | キー |
|---|---|
| 移動 | W A S D / 矢印 |
| 視点 | マウス |
| 調べる・使う | E / 左クリック(長押しあり) |
| 会話を進める | Space / Enter / E |
| クリップボード(掟とタスク) | Tab |
| ポーズ | Esc |

## 掟

一、線香を絶やさぬこと　一、灯明を絶やさぬこと　一、猫を入れぬこと　一、棺の小窓を開けぬこと　一、眠らぬこと

エンディングは4種。周回前提。
